# Sample images

These images are a redistributable quick-start library for Image Tagger:

- `beach-sunset-kayak.jpg` — outdoor scene/object and semantic-search sample
- `workspace-coffee-headphones.jpg` — indoor objects/clothing-independent CLIP sample
- `anime-neon-city-heroine.webp` — original adult anime character, pose and clothing sample

They were generated specifically for this project with the built-in OpenAI image generation tool, then resized/compressed locally. They contain no user data and are distributed under this repository's MIT License.

Suggested searches after enabling the relevant model: `beach`, `kayak`, `coffee`, `headphones`, `scene:city`, `pose:standing`, `teal hair`, or semantic phrases such as `a desk beside a window`.
